# Tiny Titans — Upgrade Archive

This folder is for code, designs, services, data models, tests, and implementation notes recovered from non-master work that are demonstrably better than the current master implementation.

## Rules

- `master` remains the sole source of truth for the live application.
- Nothing is promoted here merely because it is newer.
- A candidate must be materially better, functional, and compatible with the current architecture.
- Prefer extracting proven improvements rather than merging stale branches wholesale.
- Every promoted item should be validated against the current build, route contracts, security contracts, and relevant App/Overlord BOT journeys.
- Regional morph terminology, health/reminder improvements, enclosure intelligence, and other genuinely useful work are candidates for extraction when verified.
