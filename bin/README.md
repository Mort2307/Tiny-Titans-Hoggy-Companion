# Tiny Titans — Bin

This folder is the quarantine/archive for obsolete, superseded, abandoned, or deliberately retired implementation material.

## Rules

- `master` remains the source of truth.
- Nothing in `bin/` is part of the application runtime.
- Do not copy old code back into the app without a fresh audit.
- Creator Hub / Creator Centre experiments are retired as product architecture; useful underlying capabilities must be rebuilt to the current intelligent standard rather than resurrecting the old implementation.
- Keep historical material here only when it is useful for audit, provenance, or recovery. Otherwise remove it from the repository entirely.
