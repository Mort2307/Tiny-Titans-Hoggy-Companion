# TinyTitans Animated Icon Asset Registry

**Purpose:** Curated animated icon candidates for TinyTitans Reptile Companion.

**Review date:** 2026-09-13

**Policy:** Every account tier receives the same baseline animated icon language. Paid tiers add capability and use progressively stronger tier identity/crest treatments; animation is not withheld from Free users.

## Brand rule

TinyTitans should not look like a generic icon-pack application. Use third-party free Lottie assets for generic utility concepts where they are a strong visual fit, but reserve the app's signature reptile moments for TinyTitans-original artwork.

## Custom TinyTitans assets

These areas should become TinyTitans-original animated artwork rather than generic third-party icons:

- Feeding: snake approaches food, tongue flick, completed-feed reaction.
- Shed: snake emerging from its shed skin.
- Behaviour: expressive snake head/eye with blink, look and tongue-flick states.
- Morph Library: scale/pattern morph animation.
- Genetics: DNA helix formed from scale motifs.
- Breeding: paired eggs with a gentle rocking state and separate hatch celebration.
- Health/Vet: reptile identity combined with a restrained heartbeat/medical motif.
- Titan Intelligence: reptile eye -> spark -> insight pulse; avoid generic robot/AI imagery.
- Reptile Room / Enclosure: vivarium with subtle foliage/environment motion.
- Core TinyTitans mascot: original snake character used consistently throughout the brand.

## Licensing / distribution rule

Do not treat a LottieFiles page being labelled "free" as sufficient by itself for release approval. Record the exact asset page, creator where available, observed licence, selected format, and intended app use. Before commercial launch, re-check each asset's licence and applicable LottieFiles account/terms conditions.

LottieFiles documents that its developer handoff can provide a direct asset link and selected JSON/dotLottie version, and its current dotLottie web component can render `.lottie` and `.json` assets in a web app. The project should prefer self-hosted production assets where practical so TinyTitans is not dependent on third-party CDN availability or quotas.

## Runtime strategy

1. Curate and licence-check the asset.
2. Download the smallest suitable dotLottie or optimized JSON.
3. Store the asset under the TinyTitans public/static animation asset tree.
4. Register it in the central animated asset manifest.
5. Render through the TinyTitans animation component, not directly inside page code.
6. Preserve a TinyTitans SVG/CSS fallback and reduced-motion behaviour.

This keeps third-party animation replaceable without changing the application feature architecture.

## 2026-09-20 implementation update

The first production pass of the TinyTitans living icon system is intentionally dependency-free. The existing `TinyTitansIcon` SVG component now exposes icon state and motion attributes and includes bespoke animated environment/spatial/editor icons for:

- temperature, humidity, water, UVB and heat
- plants, substrate and hides
- Spatial Habitat Builder and Reptile Room
- veterinary and Titan Intelligence
- globe/map/camera
- add/edit/delete/eye/lock/rotate/move/resize/measure/warning/offline

These are implemented with local SVG geometry and CSS keyframes so TinyTitans does not depend on a paid icon service or a remote animation CDN for the baseline experience.

Third-party libraries remain optional sources for future specialised assets. The implementation should continue to prefer open, commercially usable licences (for example MIT, Apache-2.0 or CC0) and retain asset-level licence records before release.

The production build now includes `validate:icons`, which verifies the required icon set, motion tokens, state/motion API and reduced-motion coverage.
